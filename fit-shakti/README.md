# Fit Shakti

Customer + Admin PWA for Fit Shakti Weight Loss and Weight Gain products.

- GitHub Pages compatible
- Supabase Auth + PostgreSQL connected
- Customer/Admin role separation
- Customer profile, products, orders, food, powder, water and steps
- Admin dashboard, customers, orders and products
- Olive green, white and gray theme

Supabase project: FIT SHAKTI, ap-south-1.

The existing My_Gym repository is used without overwriting its root files. Fit Shakti is contained in `/fit-shakti/`.

Do not place Supabase secret/service-role keys in this repository. The app uses only the publishable client key and relies on RLS.
